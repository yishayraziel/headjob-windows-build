HEADJOB Refined 0.4.1 — שינוי גודל בגרירה

גרור את הסימון שבפינה הימנית התחתונה של הפלאגין.
כל הממשק גדל יחד ושומר על יחס הממדים: כפתורים, טקסט, מד, Output ו־Auto Gain.
טווח הגדלה: בערך 70% עד 200%. הגודל האחרון נשמר בתוך מצב הפלאגין בפרויקט ה־DAW.

זו גרסת Refined, עם אותו מנוע אודיו של 0.4. הפלאגין נקרא HEADJOB Refined,
מותקן בנפרד מ־HEADJOB 0.3 ומעדכן את גרסת Refined הקודמת.

Mac: העתק את ה־AU וה־VST3, או הפעל Install Refined Preview.command לאחר חילוץ.
להכנת מתקין חתום ומאומת ב־Apple, הפעל Create Signed Refined Installer.command.
כשהוא שואל לשם הפרופיל, לחץ Enter לשימוש בפרופיל HEADJOB שהגדרת קודם.
אימות Apple לא הושלם מתוך סביבת Codex; חבילת ה־ZIP עצמה חתומה מקומית בלבד.
המתקין החתום ייווצר רק לאחר ריצה מקומית מוצלחת ואישור Apple.

Windows: סגור את ה־DAW, הפעל את Setup.exe, פתח מחדש וסרוק VST3.
זוהי גרסת x64. אין חתימת Windows Authenticode.
